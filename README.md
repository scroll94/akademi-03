# OPS/9 — тактический шутер в браузере

Мини-шутер от первого лица (в духе CS:GO) на чистом HTML/CSS/JS + Three.js.
Без сборки, без npm — просто статические файлы, идеально подходит для GitHub Pages.

## Файлы

- `index.html` — разметка страницы, меню и HUD
- `style.css` — вся визуальная часть (HUD, меню, шрифты)
- `game.js` — логика игры: 3D-сцена, движение, стрельба, враги

## Как поиграть локально

Просто открыть `index.html` в браузере не всегда сработает из-за ограничений
браузера на загрузку файлов (CORS). Проще всего поднять локальный сервер:

```bash
# находясь в папке с игрой
python -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `ops9-game`).
2. Убедись, что все три файла (`index.html`, `style.css`, `game.js`) лежат
   **в корне репозитория** — имена строго латиницей, без пробелов, в нижнем регистре
   (это уже так в этом проекте).
3. Загрузи файлы в репозиторий:
   ```bash
   git init
   git add index.html style.css game.js README.md
   git commit -m "OPS/9: browser tactical shooter"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/ops9-game.git
   git push -u origin main
   ```
4. В репозитории зайди в **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Source: Deploy from a branch**,
   ветку `main`, папку `/ (root)`, и нажми **Save**.
6. Через минуту-две игра будет доступна по адресу:
   `https://ТВОЙ_ЛОГИН.github.io/ops9-game/`
