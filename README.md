# Шаңырақ Code — версия 3

Сайт онлайн-школы для подростков 14–18 лет: программирование и ИИ, математика, создание игр. Первый урок бесплатный, заявки уходят в WhatsApp.

Адрес после включения GitHub Pages: **https://scroll94.github.io/akademi-03/**
(Settings → Pages → Branch: `main`, папка `/ (root)` → Save).

## Что на главной

1. **Первый экран** с «пультом сайта»: посетитель меняет цвет, слово в заголовке и тему — и страница перестраивается на глазах.
2. **Три направления**: цветные карточки с программой и кнопкой записи.
3. **Мини-уроки**: чат-бот с редактируемым кодом, парабола с задачами, игра, где числа в коде меняют прыжок и скорость.
4. **Сделано кодом**: три 3D-сцены (часы, тессеракт, физика), открываются на весь экран.
5. **Как учимся**: четыре шага от основ до запуска проекта.
6. **Вопросы** и **форма записи** — собирает сообщение и открывает WhatsApp, на сервер ничего не отправляет.

## Файлы

- `index.html`, `style.css`, `app.js` — главная.
- `lab.css`, `lab.js` — мини-уроки.
- `demo/` — 3D-сцены для витрины.
- `legal.html` — политика конфиденциальности, согласие, пользовательское соглашение.
- `404.html`, `assets/` (иконки, превью ссылки `og.jpg`, обложки сцен).

Сборки нет. Главная работает без сторонних библиотек (только шрифты Google Fonts); Three.js и cannon-es грузятся с CDN лишь на страницах в `demo/`.
