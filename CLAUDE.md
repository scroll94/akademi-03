# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Статический сайт онлайн-школы «Шаңырақ Code» (подростки 14–18 лет: программирование и ИИ, математика, создание игр). Хостинг — GitHub Pages из `main`, корень репозитория. Язык сайта и общения с владельцем — русский.

Это третья версия дизайна: светлая «бумага», чёрная тушь, жёсткие тени, три ярких цвета. Предыдущая (тёмно-синяя с золотом и 3D-юртой) лежит в `scroll94/Shanyrak-Academy-02`; владелец просил, чтобы новая на неё не походила.

## Команды

Сборки, линтера и тестов нет. Локальный просмотр:

```bash
python3 -m http.server 8000
```

Открывать через `http://`, не `file://` (витрина грузит `demo/*.html` в `<iframe>`).

## Архитектура

- `index.html` + `style.css` + `app.js` — главная, без библиотек.
- `lab.css` + `lab.js` — мини-уроки (бот, парабола, игра); самостоятельный блок, от `app.js` не зависит.
- `demo/` — три 3D-сцены на Three.js с CDN. Главная их не грузит, пока посетитель не откроет сцену в `<dialog id="viewer">`.

Связи, которые не видны из одного файла:

- **Пульт на первом экране** (`#opt-accent`, `#opt-hero`, `#opt-theme` в `app.js`) пишет `data-accent` и `data-theme` на `<html>`. Вся перекраска — через переменные `--accent`, `--on-accent`, `--paper`, `--ink`, `--card` в `style.css`. Новым блокам нельзя зашивать эти цвета числами, иначе пульт их не перекрасит. Исключение — блоки, которые остаются тёмными или светлыми в обеих темах (пульт, мини-уроки, карточка формы): там цвета заданы числами намеренно.
- **Мини-уроки — тёмный «экран»** со своей палитрой: переменные `--night`, `--milk`, `--gold` и др. объявлены на `.lab-box` в `lab.css`, а `lab.js` читает их оттуда для рисования на холстах.
- **`[data-pick]`** на любой ссылке подставляет направление в `#f-dir` формы (обработчик в конце `lab.js`).
- **Появление блоков**: `data-rise` + класс `js` на `<html>` (ставится инлайн-скриптом в `<head>`). Без JavaScript всё видно сразу.
- **Форма** ничего не отправляет на сервер: собирает текст и открывает `wa.me`. Это отражено в `legal.html`; при появлении аналитики или сторонних сервисов документы нужно обновить.

## Ограничения

- **Только проверяемые факты.** Цен, отзывов, имён преподавателей, расписания на сайте нет, придумывать нельзя. Источники — текущие тексты и `legal.html`. Пустые реквизиты в `legal.html` (`<mark class="fill">`) заполняет только владелец.
- **Коротко.** Владелец сознательно сокращал текст: новое — в интерактиве, а не абзацами.
- **Полный адрес** `https://scroll94.github.io/akademi-03/` зашит в мета-теги и JSON-LD `index.html` и в `404.html`.
- **Поля ввода — не меньше 16px** (иначе iPhone увеличивает страницу), **без lookbehind в регулярных выражениях** (Safari на iOS 15 не разбирает и роняет весь скрипт).
- Кнопка записи на первом экране должна помещаться без прокрутки на телефонах от 360×600.
- `.claude/skills/agent-desktop` — сторонний навык (vercel-labs/agent-desktop, Apache-2.0) для управления приложениями на компьютере; к сайту отношения не имеет и работает только там, где установлена программа `agent-desktop`.
